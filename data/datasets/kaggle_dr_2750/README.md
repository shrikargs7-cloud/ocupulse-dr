# Diabetic Retinopathy Dataset (2,750 Images)

**Author / Host**: Sachin Kumar (Kaggle)  
**URL**: https://www.kaggle.com/datasets/sachinkumar413/diabetic-retinopathy-dataset?resource  

### Dataset Summary
- **Total Images**: 2,750
- **Total Class Labels**: 5

### Class Distribution
1. **Healthy (Not DR)**: 1,000 images (36.4%)
2. **Mild DR**: 370 images (13.5%)
3. **Moderate DR**: 900 images (32.7%)
4. **Severe DR**: 190 images (6.9%)
5. **Proliferative DR**: 290 images (10.5%)

### Setup Instructions
Download and unpack into this directory using the Kaggle CLI:
```bash
kaggle datasets download -d sachinkumar413/diabetic-retinopathy-dataset -p data/datasets/kaggle_dr_2750 --unzip
```
